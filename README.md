# Dev1C

**Форматирование кода 1С, работа с JSON, датами и Basic Auth — по горячей клавише.**

Dev1C — бесплатное фоновое приложение для macOS и Windows. Выделите код в Конфигураторе 1С и нажмите сочетание клавиш: Dev1C отформатирует его по стандартам 1С (отступы, пробелы, переносы длинных строк) и вставит результат на место. Отмена — обычным Ctrl+Z / ⌘Z.

По Ctrl+J открывается меню локальных инструментов: просмотр JSON с поиском и генерацией кода 1С, преобразование дат и временных меток, генератор заголовка Basic Auth. Данные вводятся вручную, результат копируется по нажатию.

## Возможности

| Команда | Windows | macOS |
|---|---|---|
| Форматировать выделение | Ctrl+Shift+Z | ⇧⌘Z |
| Форматировать весь модуль | Ctrl+Shift+A | ⇧⌘A |
| Форматировать и удалить комментарии внутри методов (по выделению) | Ctrl+Shift+X | ⇧⌘X |
| Открыть меню инструментов | Ctrl+J | Ctrl+J |

- **Форматирование в Конфигураторе.** Сочетания форматирования включаются, когда активно окно Конфигуратора. В других программах они работают как обычно. Другие редакторы (EDT, VS Code…) можно добавить в настройках.
- **JSON.** Форматирование с отступом 2/4/8 или своим от 1 до 16 пробелов, режим «Сжать», опциональная сортировка ключей, дерево данных и генерация кода 1С; поиск по Ctrl+F / ⌘F в JSON, коде и дереве. По умолчанию отступ 4, сортировка выключена.
- **Дата и время.** 10 форматов, включая Unix, Excel и Mongo ObjectID; местный пояс или UTC, системы Excel 1900/1904 и живые часы при пустом вводе.
- **Basic Auth.** Локальный генератор строки `Authorization: Basic …` из логина и пароля в UTF-8. Пароль скрыт с возможностью показа, результат копируется отдельной кнопкой. Данные не сохраняются в настройках, истории и логах; при закрытии окна поля и результат очищаются.
- **Меню инструментов.** Выбор стрелками ↑/↓ или Tab, открытие по Enter, закрытие по Esc. Base64 и RegEx отмечены «Скоро» и пока недоступны.
- **Буфер обмена не теряется.** После вставки Dev1C возвращает в буфер то, что там было до операции (текст).
- **Не вставит не туда.** Если вы переключились в другое окно, Dev1C ничего не нажимает и не вставляет.
- **Окно настроек на русском.** В нём можно:
  - переназначить сочетания (нажатием, с проверкой конфликтов);
  - включить режим «только буфер обмена»;
  - настроить список приложений, автозапуск и уведомления.
- **Автономность.** Всё необходимое встроено, Python и библиотеки ставить не нужно.
- **Код остаётся на компьютере.** Dev1C работает без интернета, в логи пишутся только итоги операций, без вашего кода.

Форматирование выполняет открытая библиотека [bslfmt](https://pypi.org/project/bslfmt/) (версия 0.27.0).

## Системные требования

- macOS 11 Big Sur и новее, Apple Silicon (M1 и новее)
- Windows 10/11 x64
- Конфигуратор 1С:Предприятие 8.3

## Установка

Приложение **не подписано** сертификатами разработчика, поэтому при первом запуске система предупредит.

### macOS
1. Откройте `.dmg` и перетащите Dev1C в «Программы».
2. После переноса приложения в «Программы» снимите атрибут карантина. Выполните в «Терминале»:
   ```sh
   /usr/bin/xattr -dr com.apple.quarantine "/Applications/Dev1C.app"
   ```
   Полный путь `/usr/bin/xattr` запускает системную утилиту macOS и предотвращает ошибку `option -r not recognized`, если в системе установлена другая версия `xattr`. При успехе команда обычно ничего не выводит.
   Или при первом запуске: «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».
3. Запустите Dev1C. Значок появится в строке меню. Значок Dock показывается, пока открыто или свёрнуто хотя бы одно окно Dev1C, и скрывается после закрытия последнего окна; приложение продолжает работать в строке меню.
4. Разрешите Dev1C «Универсальный доступ», чтобы он мог копировать и вставлять в Конфигураторе: «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ» → включите Dev1C. Перезапустите Dev1C (меню значка → «Выход», затем запуск).

**После каждого обновления** удалите Dev1C из списка «Универсальный доступ» кнопкой «−» и добавьте заново кнопкой «+». Иначе Dev1C сообщит, что разрешения нет.

### Windows
1. Запустите `.msi`. Если SmartScreen покажет предупреждение — «Подробнее → Выполнить в любом случае».
2. Запустите Dev1C из меню «Пуск». Значок появится в области уведомлений (трее).
3. Если Конфигуратор запущен **от имени администратора**, запускайте Dev1C тоже от имени администратора, иначе Windows не пропустит нажатия.

## Как пользоваться

1. Откройте модуль в Конфигураторе.
2. Выделите фрагмент и нажмите **Ctrl+Shift+Z** (⇧⌘Z) — фрагмент отформатирован.
3. Чтобы отформатировать весь модуль, нажмите **Ctrl+Shift+A** (⇧⌘A) без выделения.
4. Чтобы удалить комментарии внутри процедур, выделите процедуру целиком и нажмите **Ctrl+Shift+X** (⇧⌘X).
5. Если результат не понравился, нажмите Ctrl+Z (⌘Z).

Если код не удаётся разобрать (например, выделен `Иначе` без `Если`), Dev1C покажет уведомление и ничего не изменит. Подробности есть в меню значка → «Последняя ошибка…».

**JSON, даты и Basic Auth:** нажмите Ctrl+J или выберите «Инструменты…» в меню значка. Выберите инструмент стрелками ↑/↓ и нажмите Enter. Введите данные в открывшееся окно, затем скопируйте нужный результат. В JSON поиск открывается по Ctrl+F (⌘F на macOS). В окне дат можно оставить ввод пустым для текущего времени или ввести дату для фиксированного результата.

В Basic Auth введите логин и пароль, затем нажмите кнопку копирования готового заголовка. Пробелы и регистр сохраняются. Двоеточие в логине и управляющие символы не допускаются; двоеточие в пароле разрешено. Обычная потеря фокуса сохраняет ввод, закрытие окна очищает его. Ранее скопированный заголовок остаётся в системном буфере обмена.

**Настройки:** меню значка → «Настройки…». В окне можно:
- поменять сочетания;
- выключить автоматическую вставку (тогда Dev1C берёт текст из буфера обмена и кладёт результат обратно в буфер);
- добавить другие редакторы;
- включить автозапуск и уведомления об успехе.

## Новые версии

Внизу окна настроек всегда видны версия Dev1C, автор и ссылка на релизы. Приложение периодически проверяет новые версии на GitHub. Когда появляется обновление, оно показывает уведомление и ссылку «Скачать» в настройках. Скачивание и установка выполняются вручную.

На macOS состояние системных уведомлений видно на вкладке «Разрешения». При первом запросе можно разрешить уведомления; если доступ уже запрещён, включите его в «Системные настройки → Уведомления → Dev1C». Нажатие на уведомление о новой версии открывает настройки Dev1C на вкладке «О программе».

Если интернета нет, проверка завершается без сообщений об ошибках. Форматирование продолжает работать автономно; ваш код при проверке версии никуда не отправляется.

## Известные ограничения

- Форматирование фрагмента, выделенного внутри процедуры, может оставить строки чуть длиннее 120 знаков. Форматирование всего модуля этого ограничения не имеет.
- Команда «удалить комментарии» удаляет комментарии внутри процедур и функций, поэтому выделяйте процедуру целиком.
- Сохраняется только текстовое содержимое буфера обмена. Картинки и форматированный текст из буфера после операции не восстанавливаются.
