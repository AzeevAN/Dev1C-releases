# Dev1C

**Dev1C — desktop toolkit for 1C developers.**

Бесплатное кроссплатформенное приложение-помощник для разработчика 1С. Работает в фоне
(system tray / menu bar) поверх любого редактора — Конфигуратора 1С, EDT, VS Code и других:
выделите код, нажмите горячую клавишу — Dev1C обработает текст нужным инструментом
и вставит результат на место.

> **Статус:** в разработке. Первый релиз ещё не опубликован.

## Возможности первой версии

- **Форматирование BSL-кода** — отступы и пробелы по стандартам 1С
  (на базе открытой библиотеки [bslfmt](https://pypi.org/project/bslfmt/)).
- Работа с выделенным фрагментом или всем модулем.
- Глобальные горячие клавиши, настраиваемые для каждого инструмента.
- Автономность: всё необходимое встроено, ничего дополнительно устанавливать не нужно.

## Платформы

- macOS (Apple Silicon и Intel)
- Windows 10/11 x64
- Linux — планируется

## Установка

Установщики публикуются в разделе [Releases](../../releases).

Приложение **не подписано** сертификатами разработчика, поэтому система предупредит при первом запуске.

**macOS.** После установки в «Программы» откройте «Системные настройки → Конфиденциальность и
безопасность» и нажмите «Всё равно открыть», либо выполните в терминале:

```sh
xattr -dr com.apple.quarantine /Applications/Dev1C.app
```

Для автоматической вставки результата Dev1C запросит разрешение «Универсальный доступ»
(Accessibility). После обновления приложения разрешение может понадобиться выдать повторно.

**Windows.** Если SmartScreen покажет предупреждение — «Подробнее → Выполнить в любом случае».
